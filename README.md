# 阅词 VocabWeaver

> 让每个单词都在故事中活起来

一款智能英语阅读生成器——根据你指定的词汇，自动创作符合考试大纲难度的英语故事。

---

## 为什么选择阅词？

| 传统阅读材料 | 阅词生成的文章 |
|-------------|---------------|
| 生词太多，读不下去 | 词汇可控，难度适中 |
| 想练的词找不到 | 输入词汇，自动生成 |
| 枯燥背单词 | 在故事中自然记忆 |

---

## 核心功能

### 📝 定制词汇生成
输入你想练习的词汇，系统自动创作包含这些词汇的英语故事。

### 🎯 难度智能控制
全文词汇控制在考试大纲范围内，智能筛出超纲词，不打断阅读流畅性。

### 📖 连载续写
支持多章节连载故事，每章设定新词汇，剧情自动连贯。

### 💾 自动保存
创作进度自动保存，随时恢复继续，支持一键导出全文。

## 使用流程

```
选择风格 → 输入词汇 → 生成故事 → 续写章节 → 导出全文
```

**Step 1：选择风格**  
选择你喜欢的文章风格，如冒险故事、科幻小说。

**Step 2：输入词汇**  
输入本章想练习的词汇（如：adventure, explore, discover），设定总章节数。

**Step 3：生成故事**  
点击生成，系统自动创作包含目标词汇的英语故事。

**Step 4：续写章节**  
为下一章输入新词汇，故事自动延续，角色和剧情保持连贯。

**Step 5：导出全文**  
创作完成后，一键导出全文，随时复习阅读。
